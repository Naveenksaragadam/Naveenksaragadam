I'm a **Senior Data Engineer** at **JPMorgan Chase** with **10+ years of experience** designing, developing, modernizing, and supporting enterprise data platforms, cloud data pipelines, ETL/ELT solutions, and distributed processing frameworks across Azure, AWS, Databricks, Spark, Python, SQL, and Hadoop.

- 🔭 &nbsp;Currently building Azure data pipelines at JPMorgan Chase — **35+ production pipelines processing ~2 TB of data per day** (Azure Data Factory, Azure Databricks, PySpark, ADLS, Synapse, Snowflake)

- 🌱 &nbsp;Specializing in **Azure Databricks, Apache Spark/PySpark, real-time streaming (Kafka, Kinesis), and cloud data migration**
